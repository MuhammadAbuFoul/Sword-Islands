⚔️ Sword Islands - Unity 6 Game
A 2D action dungeon-crawler built with Unity 6 where players fight through four challenging levels filled with enemies, bosses, and strategic power-ups.

🎮 Features

* WASD movement with dash ability for tactical combat
* Directional sword combat with combo attack system
* Four levels with escalating difficulty (Orcs → Vampires → Boss)
* Progressive power-up system between levels
* Health upgrades and player progression mechanics
* Teleportation system for seamless level transitions
* Pixel art aesthetic with smooth animations
* Object pooling and optimization for performance

📂 Project Structure

* Assets/ → Scripts, sprites, animations, prefabs
* Packages/ → Unity package dependencies
* ProjectSettings/ → Unity project configuration

🚀 How to Run

1. Download this repository as a ZIP and extract it.
(Green "Code" button → Download ZIP)
2. Open Unity Hub.
3. Click Add → Add project from disk.
4. Select the extracted folder (Sword-Islands).
5. Open the project and press Play in the editor.

🕹️ Controls

* WASD → Move character
* Left Mouse Click → Attack (directional based on movement)
* Space → Dash (tactical evasion)
* Defeat all enemies to progress and unlock power-ups
