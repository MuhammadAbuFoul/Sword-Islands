# Sword Islands

A 2D action dungeon-crawler built in Unity 6, where players fight through four challenging levels filled with dangerous enemies and bosses. The game combines fast-paced combat mechanics with strategic power-up progression.

## Gameplay Features

- WASD Movement with smooth dash ability for tactical combat
- Directional Sword Combat with combo attack system
- Four Unique Levels with escalating difficulty (Orcs, Vampires, Giant Vampire Boss)
- Progressive Power-up System between levels
- Health Upgrade Mechanic for player progression
- Teleportation System for seamless level transitions
- Pixel Art Aesthetic with smooth animations

## Technical Highlights

- Object Pooling for optimized enemy and projectile spawning
- Singleton Pattern for manager systems and game state
- Efficient Design with all four levels in a single scene
- Performance Optimization for smooth gameplay

## Getting Started

### Requirements
- Unity 6 (version 6000.x or later)
- Git

### Installation

1. Clone the repository:
   git clone https://github.com/MuhammadAbuFoul/Sword-Islands.git

2. Open in Unity Hub and add the cloned folder as a project

3. Press Play to run the game

## How to Play

- Move: WASD keys
- Attack: Left Mouse Click (directional based on movement)
- Dash: Space bar (tactical evasion)
- Progression: Defeat all enemies to unlock power-ups and advance

## Project Structure

Assets/
- Scripts/ - Game logic and managers
- Sprites/ - Pixel art and animations
- Prefabs/ - Enemy and object templates
- Scenes/ - Game scene (single scene architecture)
