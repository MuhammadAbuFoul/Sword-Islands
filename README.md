# ⚔️ Sword Islands - Unity 6 Project

A 2D action dungeon-crawler built with **Unity 6 (C#)** where players fight through four challenging levels filled with enemies and bosses.

---

## 🎮 Features

- WASD movement with smooth dash ability for tactical combat.
- Directional sword combat with combo attack system.
- Four unique levels with escalating difficulty (Orcs, Vampires, Giant Boss).
- Progressive power-up system between levels.
- Health upgrade mechanics for player progression.
- Teleportation system for seamless level transitions.
- Pixel art aesthetic with smooth animations.
- Optimized with object pooling and singleton managers.

---

## 📂 Project Structure

- `Assets/` → Game scripts, sprites, animations, prefabs
- `Packages/` → Unity package references
- `ProjectSettings/` → Unity project configuration

---

## 🚀 How to Run

1. Download this repository as a **ZIP** and extract it.  
*(Green "Code" button → Download ZIP)*
2. Open **Unity Hub**.
3. Click **Add → Add project from disk**.
4. Select the extracted folder (`Sword-Islands`).
5. Open the project, then press **Play** in the editor.

---

## 🕹️ Controls

- **WASD** → Move character
- **Left Mouse Click** → Attack (directional based on movement)
- **Space** → Dash (tactical evasion)
- **Objective:** Defeat all enemies to progress and unlock power-ups
